# Launch gates

Launch only when every P0 gate passes.

| Gate | Priority | Pass condition |
|---|---|---|
| Product truth | P0 | Working/prototype/concept states are labeled consistently |
| Claim evidence | P0 | Every material claim is Approved in the Claim Ledger |
| Reward margin | P0 | Each tier has positive contribution under base and downside cases |
| Recurring boundary | P0 | Ongoing and third-party costs are visible before pledge |
| Legal/compliance | P0 | Entity, terms, privacy, IP, regulated claims, and supported regions reviewed |
| Fulfillment | P0 | Suppliers, lead times, packaging, returns, taxes, and contingency modeled |
| Security/privacy | P0 | Data flows, retention, access, breach response, and dependency risks documented |
| Timeline | P0 | Each milestone has an exit artifact and contingency |
| Support | P1 | Owners, channels, service expectations, and update cadence assigned |
| Accessibility | P1 | Page/video captions, contrast, alt text, and readable mobile layouts pass |
| Prelaunch signal | P1 | Waitlist quality and segment intent measured; no purchased-list inflation |
| Crisis plan | P1 | Delay, supplier failure, security issue, and platform rejection drafts exist |
